tklearn.utils.array.move_to_device(obj, device, non_blocking=False)[source]#

Move an object to a device.

If the object is a torch tensor or module with the provided device, it is returned as is. If the object is a mapping, list, or tuple, the function is applied recursively to each element in the object.

Parameters:

  • obj (object) – The object to move to the device.

  • device (Union[str, torch.device]) – The device to move the object to.

Returns:

output – The object moved to the device.
