class tklearn.embeddings.base.Embedding(config)[source]#

Bases: BaseModule, Mapping[str, ndarray], EmbeddingBase

Represents a loaded set of word embeddings.

Provides access to word vectors via a mapping interface and potentially an underlying text encoding model. Handles caching of processed vectors.

config#

The configuration used to load these embeddings.

Type:

EmbeddingConfig

word_to_index#

A mapping from words (vocabulary) to their integer index in the vectors array. Initialized during loading.

Type:

dict[str, int] or None

vectors#

A 2D NumPy array where each row corresponds to a word vector, ordered according to word_to_index. Initialized during loading. May be a memory-mapped array for efficiency.

Type:

np.ndarray or None

model#

An optional underlying text encoding model (conforming to TextEncoder) that might be used for generating vectors for out-of-vocabulary words or for more complex encoding tasks. Initialized during loading.

Type:

TextEncoder or None

config: EmbeddingConfig#
encode(key, **kwargs)[source]#

Get the vector for a word, potentially using the model for OOV words.

If an underlying model (TextEncoder) is available, it might be used to generate vectors for words not directly in the vectors table or to handle multi-word expressions by averaging sub-word vectors. Otherwise, it falls back to __getitem__. Results are cached.

Parameters:

  • word (str or list[str]) – The word or phrase to get the vector for.

  • **kwargs – Additional keyword arguments for the encoder.

Returns:

The vector representation of the word.

Return type:

np.ndarray
