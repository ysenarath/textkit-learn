freeze_layers(layers=None, prefix='')[source]#

Freeze layers in the model that match the given patterns.

Parameters:

  • layers (list of str, optional) – A list of layer names or patterns to freeze. Supports wildcards (*) and dot notation for nested layers. If None, no layers will be frozen.

  • prefix (str, default="") – An optional prefix to apply to all layer patterns.

Returns:

The number of parameters frozen.

Return type:

int

Raises:

ValueError – If an invalid regex pattern is provided.

Examples

>>> model.freeze_layers(['encoder.*', 'encoder.layer.[0-8].*'])
>>> model.freeze_layers(['layer_[1-3]'], prefix='transformer')

Notes

This method uses regular expressions to match layer names. Dots in layer names are treated as literal dots, while asterisks are treated as wildcards.
